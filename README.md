# BI Agent

This repository is a Mastra project initialized with `bunx create-mastra`.

The current goal is simple:

- keep the Mastra app working as generated
- use `dashboard-workspace/dashboard-app` as the place where you manually test Evidence
- avoid mixing generated dashboard files into the Mastra source tree

## Run Mastra

Start Mastra Studio from the repository root:

```shell
bun run dev
```

Mastra Studio runs at `http://localhost:4111`.

The generated Mastra code lives under `src/mastra`.

## Test Evidence Separately

Use `dashboard-workspace/dashboard-app` for your manual Evidence experiments.

Typical flow:

```shell
cd dashboard-workspace/dashboard-app
npm create evidence@latest .
npm install
npm run sources
npm run dev
```

When you want a production build:

```shell
npm run build
```

## Current Repo Shape

- `src/mastra`: Mastra app code generated by the CLI
- `dashboard-workspace/dashboard-app`: local Evidence sandbox
- `docs`: project notes and planning documents
